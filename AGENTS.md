# Repository Guidelines

## Release Versioning

- Use semantic versions in `a.b.c` form.
- For a normal release, keep `a` unchanged, increment `b` by exactly one, and reset `c` to zero. For example, the release after `1.4.3` is `1.5.0`.
- For a small hotfix, keep `a` and `b` unchanged and increment `c` by exactly one. For example, the hotfix after `1.4.3` is `1.4.4`.
- Increment `a` only when the user explicitly instructs you to do so. When incrementing `a`, reset `b` and `c` to zero.
